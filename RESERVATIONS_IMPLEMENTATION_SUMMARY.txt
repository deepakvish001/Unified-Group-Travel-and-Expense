10. USAGE INSTRUCTIONS
───────────────────────────────────────────────────────────────────────────────

FOR END USERS

1. Open a trip in WayFare
2. Click the new "Services" tab (🧭 icon)
3. Click "Find My Location" button
4. Grant location permission
5. Browse nearby services by category
6. Click a service card to view details
7. Click "Reserve Now"
8. Fill in dates and any notes
9. Click "Confirm Reservation"
10. View reservation in My Reservations tab

FOR DEVELOPERS

Import and use:
  import { ReservationsPanel } from '@/components/panels/ReservationsPanel';
  import { SavedReservations } from '@/components/module4/SavedReservations';

Query data:
  const { data } = await supabase
    .from('service_reservations')
    .select('*')
    .eq('trip_id', tripId);

Extend functionality:
  - Modify mock data in loadMockServices()
  - Add real API calls replacing mock data
  - Customize service categories in CATEGORY_CONFIG
  - Add payment integration to ReservationForm
